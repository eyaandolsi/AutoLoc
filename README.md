## Acteurs et cas d'utilisation 

### Client
- Consulter le catalogue des véhicules disponibles (par catégorie, agence, dates)
- Effectuer une réservation de véhicule
- Consulter l'historique de ses réservations et contrats
- Signer un contrat de location
- Effectuer un paiement
- Annuler une réservation

### Agent d'agence
- Enregistrer un nouveau client
- Créer, modifier ou confirmer une réservation
- Établir un contrat de location
- Enregistrer un paiement
- Mettre à jour le statut d'un véhicule (disponible / loué / en maintenance)
- Signaler une intervention de maintenance

### Responsable d'agence
- Superviser les activités de l'agence (réservations, contrats, paiements)
- Gérer le parc de véhicules de l'agence (ajout, retrait)
- Gérer les employés de l'agence (agents)
- Consulter les statistiques et rapports d'activité de l'agence

### Administrateur
- Gérer l'ensemble des agences (création, modification, suppression)
- Gérer les comptes utilisateurs et leurs rôles (Agent / Manager)
- Superviser l'ensemble du système AutoLoc
- Gérer le référentiel d'équipements
- Consulter les statistiques globales, toutes agences confondues
